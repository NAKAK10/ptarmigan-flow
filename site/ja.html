押して話す。
離せば、文字に。

ptarmigan-flow は macOS 向けのプッシュトゥトーク音声入力デーモンです。右 ⌘ キーを押している間だけ録音し、離すとローカルの音声認識モデルが文字起こしして、アクティブなアプリへそのまま入力します。音声があなたの Mac の外へ送られることはありません。

⌘hold REC → 金曜までにリリースノートをお送りします。

Mac アプリをダウンロード

署名・公証済み · macOS 14 以降 · Apple Silicon（arm64）

PtarmiganFlow.zip をダウンロード

Homebrew でインストール

brew tap nakak10/ptarmigan-flow https://github.com/NAKAK10/ptarmigan-flow
brew install ptarmigan-flow

続けて3 つのセットアップコマンドを実行してください。

デモ

実際の入力の様子

ptarmigan-flow を使っている様子の短い録画です。キーを押して話すと、文字起こし結果がアクティブなアプリに入力されます。

使い方

ウィンドウいらずの 4 ステップ

  1. 1

    押す

    どのアプリでも、右 ⌘ キーを押し続けます。すぐに録音が始まります（既定で最大 30 秒）。

  2. 2

    話す

    入力したい内容を話します。録音中は画面上の小さなインジケーターでお知らせします。

  3. 3

    離す

    キーを離すと、ローカルのモデルが Mac 上で文字起こしを行います。音声のアップロードは行いません。

  4. 4

    入力される

    文字起こし結果がアクティブなアプリへ直接タイピングされます。クリップボード貼り付けも選べます。

特長

プライバシー第一、流れを止めない

ローカルで完結、プライベート

音声認識はすべて Mac 上で実行します。クラウド送信・アカウント登録・テレメトリーはありません。このページも外部アセットを読み込みません。

選べるローカルモデル

Moonshine（tiny / base）、IBM Granite Speech（既定）、MLX 版 Whisper large-v3-turbo、Mistral Voxtral、vLLM サーバーモードに対応しています。

補正もローカルで

補正辞書で固有名詞などの誤変換を直せるほか、Ollama / LM Studio 経由のローカル LLM による後処理補正も利用できます。

自然な入力方法

直接タイピングならクリップボードを汚しません。クリップボード貼り付けモードへも設定ひとつで切り替えられます。

ログインと同時に起動

launchd エージェントを一度インストールすれば、ログインのたびに自動で待機します。常駐ウィンドウはありません。

邪魔をしない設計

録音・文字起こし中は小さなアクティビティインジケーターを表示できます。録音は既定で最大 30 秒です（変更できます）。

インストール

2 つの導入方法

1 — Mac アプリをダウンロード

  1. zip をダウンロードして展開します。
  2. PtarmiganFlow.app をアプリケーションフォルダへ移動して開きます。
  3. 表示される案内に従って、下記の 3 つの権限を許可します。

アプリは署名・公証済みです。それでも初回起動時に macOS の警告が出る場合は、アプリを右クリックして「開く」を選択してください。

PtarmiganFlow.zip をダウンロード

2 — Homebrew

brew tap nakak10/ptarmigan-flow https://github.com/NAKAK10/ptarmigan-flow
brew install ptarmigan-flow

続けて、インストールの確認・権限のリクエスト・デーモンの起動を行います。

pflow doctor
pflow check-permissions --request
pflow run

pflow は ptarmigan-flow の短縮エイリアスです。

権限設定

3 つの macOS 権限について

ptarmigan-flow はキー入力の検出、音声の録音、テキストの入力を行うため、それぞれに対応する権限が必要です。次のコマンドで 3 つまとめてリクエストできます。

pflow check-permissions --request

マイク

音声を録音するために必要です。録音するのはホットキーを押している間だけです。

システム設定 → プライバシーとセキュリティ → マイク

アクセシビリティ

文字起こし結果をアクティブなアプリへ入力（または貼り付けのキー操作を送信）するために必要です。

システム設定 → プライバシーとセキュリティ → アクセシビリティ

入力監視

ほかのアプリにフォーカスがあるときでも、グローバルホットキー（右 ⌘）を検出するために必要です。

システム設定 → プライバシーとセキュリティ → 入力監視

ダウンロードしたアプリの初回起動について: アプリは署名・公証済みのため、通常はそのまま開けます。Gatekeeper の警告が表示された場合は、PtarmiganFlow.app を右クリックして「開く」を一度選択してください。

権限を許可した後は: すでに launch agent としてデーモンが動作している場合、pflow restart-launch-agent で権限を反映してください。
